# UT2 · Programación multihilo

Proyecto de prácticas de la unidad. Cada bloque del cuaderno tiene su paquete (`b1`, `b2`… `b6`).
Los ficheros con «código de partida» traen comentarios que dicen qué completar.

## Cómo ejecutar

- Desde IntelliJ: el triángulo verde junto a `fun main()` de cada programa.
- Desde la terminal: `gradlew.bat run -q -Pprograma=com.iesvb.psp.ut2.b1.<Clase>Kt` (en Linux, `./gradlew`).
- Pruebas: `gradlew.bat test`.

## Notas

Este fichero es tuyo: apunta aquí lo que te sirva (cómo has resuelto cada bloque, el diseño del
proyecto B6, dudas para clase…). No se entrega.
